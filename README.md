# Stereo-Vision-Depth-Mapping-Analysis

Bu proje, stereo vision teknolojisinin tarihsel gelişimini ve modern derinlik haritalama tekniklerini inceleyen kapsamlı bir çalışmadır.

## 📄 Proje İçeriği
- **Akademik Rapor:** İbn-ül Heysem'den günümüze stereo vision teorisi, epipolar geometri ve disparite haritaları üzerine teknik inceleme.
- **Python Uygulaması:** OpenCV kütüphanesi kullanılarak yazılmış, iki görüntü arasındaki derinliği hesaplayan temel blok eşleme (Block Matching) algoritması.

## 🛠️ Kullanılan Teknolojiler
- Python
- OpenCV
- Matplotlib
